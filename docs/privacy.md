# Privacy

Principles: audio only on explicit push-to-talk first; device shows when capturing (LED/screen, hardware TBD); no continuous recording by default; local-first processing where practical, and each provider documents whether it uses the internet.
Stores kept separate: device telemetry, companion memory, sensitive reflections (psychology), relationship reflections. Reflections are never visible to the owner/partner without her explicit per-item permission. View, correct, delete, export, and retention controls are required before any memory feature ships.
Status: ordinary memory and the reflection vault are implemented (`companion/memory`, tested): separate SQLite files bound to one user_id, AI inferences held `pending` until confirmed, vault off by default with consent per write and no AI interpretations, hard delete, per-category clear, retention purge, export.
Encryption at rest (optional, `passphrase=` on `MemoryStore` / `ReflectionVault`; `python -m tools.memory_crypt encrypt` converts an old file): AES-256-GCM per field (key, value, tags, source context), scrypt key, ciphertext bound to user+row+field so values cannot be swapped, tamper detected. Still visible to someone holding the file: category, status, source, confidence, timestamps, row count, and whether two rows share a key. Protects a stolen disk or backup; does NOT protect against someone using the running host, and the passphrase must not sit next to the file. Lose the passphrase and the memories are gone (no recovery). The old plaintext file is deleted on migration but its disk blocks are not scrubbed. Tested with unit tests only; not yet wired into any startup config, so the companion still opens its stores unencrypted until a caller passes a passphrase. Whole-file encryption (SQLCipher) or OS disk encryption is still the stronger layer and can be added on top.
Gaps: no sentiment/semantic retrieval (lexical only), no UI for review yet, sensitive-term screen is a crude keyword list that will miss things.

Conversation (LLM): the default adapter only talks to loopback/private addresses and ignores proxy env vars; sending conversations off-network needs `allow_remote=True` in code. The prompt receives her name and up to 5 retrieved active memories (never pending ones, never reflections). Chat history stays in RAM (last 6 exchanges) and is not persisted. Anything the model proposes to remember is checked against her own words; ungrounded proposals wait for her yes.

Psychology: reflection content lives in RAM for the session; the private vault gets only what she approves, in her own words. Settings and reminders hold no content. Listening mode is available only to a model marked local. A crisis message is answered with fixed text, never sent to a model and never stored. No path exists to give another person her notes.
